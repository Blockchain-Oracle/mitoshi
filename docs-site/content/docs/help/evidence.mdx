Each stage of the build records its live runs in `docs/plan/acceptance/S<n>.md`: what was run, against which deployment, and every transaction after `cast receipt` read it back with status 1. A receipt is a completed action, not a current position or a payout today. The runs used fresh test accounts, so there is no single demo wallet.
