Ops is one Node process on Mitoshi's Coolify server, at `ops.testnet.mitoshi.xyz`. Every actor runs on the same loop (`runActor`): a pass every few seconds, a heartbeat, a one-line reason for what it did or why it waited. Each actor that signs has its **own role key**; an actor with no key runs dry. Dry run is the default until it is switched off, actor by actor.

## The actors

Read from ops' `/health` on 12 October 2026 (21 heartbeats, 20 live, 1 dry):

| Actor | Job |
| --- | --- |
| chain-head | Follows Moderato's head; the venue's liveness. |
| spot-feed | RedStone's latest signed packages, every feed, every 10 s. |
| display-crypto · display-stocks | The chart's live line: Coinbase for crypto, Alpaca for stocks. Never settlement. |
| window-roller | Opens the next Window of each of the 66 series; holds the roller role. |
| price-relay | Posts RedStone packages for each boundary to the engine. |
| archive | Keeps RedStone's packages for every boundary, apart from any transaction. |
| settler | Settles, voids at the deadline, and pays winners (`redeemFor`); cranks the Trading Balances' settled positions. |
| seed-maker | The house maker: both sides of every live Window, around the fair value, to lock − 30 s. |
| house-taker | House-key taker fills so the books see flow. Its fills are never counted as demand. |
| earn-quoter | The maker vault's quotes on the crypto Windows. |
| exit-keeper | Sells armed exits through EXIT grants, at the floor. |
| leverage-keeper | Settles and knocks out boosts. |
| strategy-runner | Places for copiers through STRATEGY grants; runs house agent #3's model. |
| agent-rater | One ERC-8004 rating per agent per completed day. **Dry** until the owner releases it. |
| halt-watch | The halt board from RedStone freshness and Alpaca's tradable flag. |
| calendar · earnings | NYSE sessions and holidays; upcoming earnings. |
| funds-watch | Watches every role key's pathUSD against a floor and tops a low one up from Moderato's faucet (mainnet only reports). |
| moderation | The social report queue. Reads only. |
| indexer | The chain into Postgres. |

Three more exist and are not running on testnet: **reference-writer** (keeps the stock reference fresh, opt-in), **launch-keeper** (graduates complete memecoins; plans only, opt-in) and **indexer-recount** (an hourly recount against the Tempo Indexer API or a self-hosted tidx).

## The indexer

The indexer follows the engine, the three Trading Balance vaults, the strategy registry and the ERC-8004 reputation registry, block by block, into Postgres — Windows, orders, fills, prints, settlements, vault executions and grants. At 22:06 UTC on 12 October it had seen 60,381 Windows opened and 60,320 resolved (`evidence/ops-health-2026-10-12.json`). Web reads it for Markets, Portfolio, Stats, the leaderboard and profiles.

**Recount.** A separate replay — a GitHub workflow, `recount.yml` — walks the engine's and every vault's logs and compares totals with the index. The S5 gate passed with the recount equal to the index, total for total and Window for Window, through block 39,012,040.

## The stream

Ops serves one live stream to the terminal: public topics (prices, ticks, sessions, halts) are open, and your own topic needs a 60-second ticket the web signs. A refused ticket keeps the public stream.

## Health

`/health` lists every actor's last pass, its reason, its failures and whether it is dry; <AppLink href="/status">Status</AppLink> shows it in the app with the relay's state. The container's health check uses `/livez`, so an outage at RedStone doesn't take the ops API down.
