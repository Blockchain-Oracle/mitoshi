On a desk they sit in the rail on the left. On a phone the dock holds Trade, Markets, the 見通し seal, Portfolio and **More**.

## More

**More** lists everything that is not a place, grouped:

- **More ways to trade:** Short (the terminal on Boost, DOWN picked), Parlay, Earn, Themes, Launch, Bridge, Backing, Market Surface, Sensei, X-trade.
- **Learn:** Demo, News, How it works, Download, Reels, Docs (these guides), Reference (the app's own short pages), Pitch.
- **Games:** Practice, Duel, Lucky, Range, Moonshot, Line Rider, Candle Hop.
- **Automate:** Agents.
- **Records and proof:** Activity, Trader Edge, Stats, Game ranks, Games history, Status, Trading halts, Print proofs.
- **Account:** Account & keys, Notifications, X recovery.

More's search pill opens the same search as ⌘ K.

## Search and shortcuts

| Keys | Does |
| --- | --- |
| 1 – 6 | Jump to a place |
| ⌘ K or / | Search: the six places, then every asset with a live Window, then stocks and every page as you type |
| ? | The shortcut list |
| Esc | Close the open drawer or dialog |
