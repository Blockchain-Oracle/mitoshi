**Mitoshi** (`xyz.mitoshi.app.testnet`) is an Expo app that opens <AppLink href="/">the site</AppLink> in one native web view. Same passkey, same account, same test dollars.

## What the shell adds

- A splash held until the page paints, and a status bar that follows the theme.
- Android Back walks the page's history.
- Other sites open in the system browser; downloads go to the share sheet.
- An offline screen that retries by itself.

## Passkeys

Your passkey belongs to `mitoshi.xyz`. A native app may use it only when that domain names the app, and since 13 October it does: `https://mitoshi.xyz/.well-known/apple-app-site-association` (iOS) and `/.well-known/assetlinks.json` (Android) answer with the app's team and signing key. On Android the shell turns on the web view's WebAuthn.

## Where to get it

| | State |
