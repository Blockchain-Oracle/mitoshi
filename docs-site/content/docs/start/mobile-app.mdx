**Mitoshi** (`xyz.mitoshi.app.testnet`) is an Expo app that opens <AppLink href="/">the site</AppLink> in one native web view.

## What the shell adds

- A splash held until the page paints, and a status bar that follows the theme.
- Android Back walks the page's history.
- Other sites open in the system browser; downloads go to the share sheet.
- An offline screen that retries by itself.

## Passkeys

Your passkey belongs to `mitoshi.xyz`. A native app may use it only when that domain names the app, and since 13 October it does: `https://mitoshi.xyz/.well-known/apple-app-site-association` (iOS) and `/.well-known/assetlinks.json` (Android) answer with the app's team and signing key. On Android the shell turns on the web view's WebAuthn.

## Where to get it

| | State |
| --- | --- |
| iOS · TestFlight | Built on EAS. The App Store Connect record exists; the public link follows Apple's beta review |
| Android · Google Play testing | Built on EAS. Internal testing, for invited testers; Play's signing key is in `assetlinks.json`. Open testing comes next |

<AppLink href="/download">Get the app</AppLink> offers each public link the moment it is set, with a QR code for a computer. Play's internal test opens only for invited testers, so there it stays quiet and the web app leads.
