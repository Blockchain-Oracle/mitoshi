Open <AppLink href="/download">Download</AppLink> on your phone and choose **Install Mitoshi**.

- **iPhone (Safari):** tap Share — the square with the arrow — then **Add to Home Screen**, then **Add**.
- **Chrome and Edge:** use the install icon at the right of the address bar, or **Install** in the browser menu.

The installed app is the same site: the same passkey, the same account, the same testnet dollars. There is no store listing.

<Callout title="Native app">
Native iOS and Android builds are specified (`docs/specs/mobile.md`, stages SM1–SM5) and not built yet. Nothing here claims a store release.
</Callout>
