## Where the code came from

Mitoshi ports code its author wrote before this hackathon, and says so file by file: **Masayume** (contracts, packages and the web app, moved from their old chain to Tempo), **Agari** (the events-engine semantics, rewritten in Solidity; the ops runtime; the wallet modal), **Owarine** (the trading terminal and the round-4 product surfaces), **Senryo** (the games hall and the arcade) and **Baku** (the app shell). Ported files carry `Ported from <app> <commit>:<path>`. Third-party material, including 21st.dev components, is listed in `THIRD_PARTY_NOTICES.md`.
