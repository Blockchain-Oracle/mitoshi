## Findings

- F-S13-01: testnet ops runs an explicit `OPS_ACTORS` list, so the new default `moderation` actor didn't start on the
  first deploy. The queue only reads, so ops starts it whenever `DATABASE_URL` is set (e755ab9).
- F-S13-02: the live check's key reported its own take and the API took it. Reports on your own post or profile are
  refused now (400 "That's yours — edit or delete it instead."); the live check reports from a second key.
- F-S13-03: `useBookDepth(null)` threw "Cannot read properties of null (reading 'decimals')": the React Compiler
  memoizes on what the read callback touches and hoisted `market!.decimals` into that check. No caller passed null
  until Sensei's drawer opened before a Window loaded. The three hooks now read `decimals` outside the callback.
- F-S13-04: the first Sensei deploy failed with `ENOSPC` — the Coolify box was at 144 of 145 GB, mostly old Mitoshi
  images kept for rollback (17 ops and 46 web images, ~2 GB each). The ones older than the two newest per app were
  removed (no force; running images and every volume untouched), freeing 33 GB; the redeploy passed. Coolify's image
  retention for both apps needs a lower limit (owner action), or this recurs within days.
- F-S13-05: with a valid social session but no connected wallet (the session outlives the wallet's connection), the
  page showed the person as signed in yet "Post take" opened the sign-in modal — `ensure()` required a wallet even
  though the server checks only the session (found by the `s13-draft` driver, run 38090984421; the caption did survive).
  `ensure()` now accepts the existing session when no wallet is connected.
- F-S13-06: the backup flow as one click (create on the other device, then sign the authorisation here) failed under
  Chrome's virtual authenticators with both authenticators present (`send-unknown`, "An error occurred."), while an
  unsponsored root send (Withdraw $1) passed. Two steps — create, then "Confirm with this passkey" — pass, and read
  better with two devices. Not yet checked: arming one-tap trading while signed in with a backup.
